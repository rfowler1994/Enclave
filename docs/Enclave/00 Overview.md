# Identity
Enclave is a modular workspace for preparing and running tabletop RPG sessions. It brings specialized modules together in a customizable environment where DMs can organize information, manage sessions, and access their tools without constantly switching applications. Enclave adapts to different DM workflows rather than prescribing a single way to prepare or run a game.
# Design Principles

| Principle        | Description                                                                                                           |
| ---------------- | --------------------------------------------------------------------------------------------------------------------- |
| Flexibility      | DMs should be able to customize their workspace to fit their workflow.                                                |
| Modularity       | Features should have clear responsibilities and work together without unnecessary dependencies.                       |
| Simplicity       | Basic functionality should be easy to use without requiring extensive configuration.                                  |
| Extensibility    | The application should allow new functionality to be introduced without requiring major changes to existing features. |
| Interoperability | Modules should be able to share relevant resources and information through Enclave.                                   |
| DM Control       | DMs should determine how they organize their content, use their tools, and share information with players.            |
