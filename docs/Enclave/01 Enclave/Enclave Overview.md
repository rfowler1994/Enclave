# Description

Enclave is the central workspace that hosts and connects [[Modules]], providing the shared functionality needed to organize and operate a DM's tools within a single application.

Enclave manages windows, layouts, module lifecycles, workspace context, and resource discovery. Individual modules provide specialized functionality while relying on Enclave for shared services and communication with other modules.

The goal is to provide a flexible, customizable workspace where DMs can arrange and access their tools without being restricted to a fixed interface.
