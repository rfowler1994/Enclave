This document outlines the primary technologies selected for developing [[Enclave Overview|Enclave]] and the reasoning behind those choices.
# C\# / .NET
- **Purpose:** Primary programming language and development platform.
- **Reasoning:** Builds on existing .NET experience while providing an opportunity to strengthen C# skills and learn software architecture through a new application.
# Avalonia
- **Purpose:** Cross-platform desktop UI framework.
- **Reasoning:** Allows Enclave to support Windows, Linux, and macOS while remaining within the .NET ecosystem.
- **UI Markup:** XAML, used to define the application's interface.
